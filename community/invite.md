# 邀请点评

一次只请人看一节课，给一个能直接打开的链接，问具体的问题。

课件链接：Python 用 `https://lixuanan2.github.io/python-for-youth/04-conditions/index.html` 这种写法，把课的文件夹名换掉。C++ 把 `python-for-youth` 换成 `cpp-for-youth`。

## 找谁

| 人 | 能看出什么 |
| --- | --- |
| 一线信息老师 | 课堂节奏，学生会卡在哪里 |
| 做程序员的家长 | 讲错的地方，说法到后面成不成立 |
| 教育研究者 | 学习顺序和练习设计 |
| 这个年纪的学生 | 看不看得懂，想不想继续 |

先找三到五个人，看完第一批的反馈，把重复出现的问题改掉，再请下一批。

## 发给老师和程序员

> 您好，我在做一门给小学高年级和初中生的 Python 课，课件和代码都公开。想请您帮忙看一节课，大约 15 分钟：
>
> <课件链接>
>
> 按方向键翻页。想请您回答三个问题：
>
> 1. 哪里学生最可能卡住？
> 2. 哪里讲得不对，或者说法以后会误导学生？
> 3. 如果必须删掉一页，您删哪一页？
>
> 直接回复我就行。有 GitHub 账号的话，也欢迎提 Issue：
>
> https://github.com/lixuanan2/python-for-youth/issues/new/choose

## 发给家长

先问过家长，再请孩子看。不要收集孩子的姓名和学校，也不要拍照。

> 您好，我在做一门给小学高年级和初中生的 Python 课。想请孩子试着自己看一节，大约 20 分钟，看完告诉我：
>
> 1. 哪一页看不懂？
> 2. 哪个地方最有意思？
> 3. 还想看下一节吗？

## 问卷

给没有 GitHub 账号的人用。问卷工具由老师选，不要收集姓名和联系方式这类必填项。

1. 您的身份：老师、程序员、家长、学生、其他
2. 看的是第几课
3. 哪一页学生最可能卡住？为什么？
4. 哪里讲得不对，或者说法以后会误导学生？
5. 如果必须删掉一页，您删哪一页？
6. 想留联系方式的话可以写在这里（选填）

## 收到意见后

- 把意见记成 Issue，写清第几课第几页，不写对方和学生的身份信息。
- 查证后再改：先确认问题存在，再决定改不改，以自己的课为主。
- 改动对另一门课也有用的话，提到另一门课里。
